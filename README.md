# EigenvaluesMultilinearFormsGraph
This repository contains code, data and additional material associated to the work Eimear Byrne and I have done on the multilinear froms graph eigenvalues and its applications to tensor-codes bounds 

_Article:_ The multilinear forms Cayley graph and the eigenvalue method for tensor codes, by Eimear Byrne & Lucien François. \
_Status of the paper:_ Submitted to SIDMA (SIAM), under review. Open-source arXiv TBD.

*Note:* The file `MAGMAFUNCTIONS.m` is a file containing a lot of functions (linear algebra, combinatorics, tensor-algebra, finite fields). It is required to run functions in the file `MultilinearFormsSpectra.m`. If you want to use the latter, download the former and put it into the same folder (or copy-paste the required functions).
